# Рабочие заметки

Статические материалы и расчёты по Colonization KLT.

Входная страница — `index.html`; отдельное расписание — `schedule.html`.
Сайт не меняет игру или сохранения. Расписание является планом, а не результатом симуляции партии.

Модели: `python calculations.py`. Для проверки исходников: `python calculations.py --verify-sources --game-root "ПАПКА_ИГРЫ"`.

Личные пути к файлам исключены из веб-копии. Исходный локальный пакет сохранён отдельно.
Директивы noindex и robots.txt просят поисковые системы не индексировать сайт; доступ по URL открыт.
